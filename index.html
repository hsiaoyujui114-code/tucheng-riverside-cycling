學府公園出發・安全進河濱指南

重要安全守則：避開擺接堡路大型砂石車！

土城區小騎士絕對禁行路段提醒：

土城堤外的「擺接堡路」是連接板橋與三峽的大型砂石車與貨車幹道，車速極快且無自行車專用道！國小六年級同學請絕對不要直接騎上擺接堡路平面。請一律透過市區道路接「自行車牽引道」或「水門引道」跨越堤防進入堤外自行車道！

通道一：浮洲橋自行車牽引道（往北：新月橋、大稻埕、淡水、八里）
  1. 學府公園集合出發，沿學府路一段前行，轉入裕民路。
  2. 經海山捷運站商圈直行接中華路一段人行道/慢車道。
  3. 到達浮洲橋下，依照標示推車上「浮洲橋自行車專用引道」。
  4. 安全抵達大漢溪右岸自行車道！從此全程無汽車干擾。
通道二：城林大橋牽引道 / 媽祖田水門（往南：鶯歌陶瓷老街、三鶯之心）
  1. 從學府公園走裕民路直行，左轉中華路一段/二段。
  2. 至城林大橋前，走人行陸橋與自行車專用牽引道安全跨越防汛堤防。
  3. 或沿中央路三段/四段慢車道前進至媽祖田水門專用自行車便道。
  4. 進入大漢溪右岸後一路向西南奔馳，路面筆直平坦！

如何發布到 GitHub Pages？

這是一個純靜態網頁，免費上傳即可分享！

步驟 1：建立 GitHub 新儲存庫 (Repo)

到 github.com/new 建立一個公開 (Public) 的 Repo，例如取名為 tucheng-riverside-cycling。

步驟 2：上傳專案檔案

在你的終端機或 Git 軟體中執行：

git remote add origin https://github.com/你的帳號/tucheng-riverside-cycling.git
git branch -M main
git push -u origin main

步驟 3：開啟 GitHub Pages 免費網頁

進入該 Repo 的 Settings -> 點選左側 Pages -> 在 Build and deployment 選擇 Deploy from a branch -> Branch 選 main / / (root) -> 按下 Save！

約 1 分鐘後，你就會獲得一個屬於你的專屬網址，手機點開就能直接看！
