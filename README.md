## 🚀 如何部署到 GitHub Pages（3 步驟免費上線）

這個專案是 100% 的**純靜態網頁（Static HTML）**，完全不需安裝 Node.js 或後端伺服器！

### 步驟 1：建立 GitHub 儲存庫
1. 打開瀏覽器，前往 [GitHub.com](https://github.com) 登入你的帳號。
2. 點擊右上角的 **+** 號，選擇 **New repository**。
3. Repository name 輸入：`tucheng-riverside-cycling`（或你喜歡的名字）。
4. 設定為 **Public**（公開），其他選項不勾選，按 **Create repository**。

### 步驟 2：推送程式碼到 GitHub
在你的終端機中，切換到本專案資料夾，依序輸入：

```bash
git remote add origin https://github.com/<你的GitHub帳號>/tucheng-riverside-cycling.git
git branch -M main
git push -u origin main
```

### 步驟 3：開啟 GitHub Pages 免費網址
1. 在 GitHub 該專案頁面上方，點擊 **Settings**（設定）。
2. 在左側選單中找到 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch**：
   - 選擇 `main` 分支。
   - 資料夾選擇 `/ (root)`。
   - 點擊 **Save**（儲存）。
4. 等待約 1 到 2 分鐘，重新整理頁面，最上方就會出現你的專屬網址：  
   👉 `https://<你的GitHub帳號>.github.io/tucheng-riverside-cycling/`
5. 用手機打開這個網址，就能在騎車時隨時查看囉！
